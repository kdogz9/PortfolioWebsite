Game Development

These are some of the games I have created throughout my time studying Games Development. Each project has allowed me to explore different areas of programming, game design and art direction.

Fairy Sky Glade

Fairy Sky Glade is a 2D platform game where you play as a fairy collecting orbs and power-ups to progress through procedurally generated levels.

The game also uses the Open-Meteo API to alter the environment and gameplay depending on real-world weather.

My Role: Programming, game design, procedural generation and API integration.

Created with: C, Raylib, Open-Meteo API

Play on Itch.io

Lizard Eggsplore

Lizard Eggsplore is a 3D platform game where the player controls a rolling lizard moving through an obstacle course and collecting eggs for points.

My Role: Gameplay programming, game design and Unity implementation.

Created with: C#, Unity
